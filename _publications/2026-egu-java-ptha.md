title: "A two-stage framework for a large-scale probabilistic tsunami inundation hazard assessment: A study case for the southern coast of Java, Indonesia"

excerpt: "Large-scale probabilistic tsunami inundation hazard assessment is computationally demanding due to the vast number of scenarios and high coastal resolution required. This study presents a modular two-stage framework coupling offshore propagation (JAGURS) with high-resolution inundation modelling (SFINCS), applied to over 1,000 km of the southern Java coastline using open-source DEMs. The framework is designed to be scalable and adaptable, enabling progressive development at national, regional, or global scales."
